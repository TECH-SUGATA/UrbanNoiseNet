# UrbanNoiseNet

Smart city acoustic intelligence platform — real-time noise classification, geofencing, and civic enforcement dashboard.

## Structure
- `/backend` — FastAPI service (MFCC + Random Forest audio classification)
- `/frontend` — React/Vite dashboard (deployed on Vercel)

## Tech Stack
- Backend: FastAPI, scikit-learn, librosa
- Frontend: React, Vite, Tailwind
- Deployment: Render (backend), Vercel (frontend)
